Alternative interne Namen:

BrickVerse

Dieses Projekt ist KEIN einzelnes Spiel.

Es ist eine Plattform, eine Sammlung und ein Framework, in dem zukünftig dutzende bis hunderte GameJam-Spiele entstehen können.

PROJEKTVISION

Das Projekt ist ein zentraler Hub, von dem aus der Spieler verschiedene Minigames betreten kann.

Jedes Minigame wird während zukünftiger Game Jams entwickelt.

Alle Spiele müssen dieselben Assets verwenden.

Dadurch entsteht eine kohärente visuelle Identität.

Die Plattform wächst über Jahre hinweg.

Neue Spiele können jederzeit hinzugefügt werden, ohne bestehende Systeme zu verändern.

Das Projekt muss daher extrem modular aufgebaut werden.

CORE PHILOSOPHY

Folgende Prinzipien gelten IMMER:

Modularität über alles.
Kein Minigame darf hart in das Hauptsystem eingebaut werden.
Jedes Minigame ist ein eigenständiges Modul.
Das Hauptmenü entdeckt neue Spiele automatisch.
Neue Spiele können hinzugefügt oder entfernt werden.
Assets werden zentral verwaltet.
Wiederverwendbarkeit hat höchste Priorität.
Saubere Architektur ist wichtiger als schnelle Lösungen.
Systeme müssen skalierbar sein.
Niemals Duplikate erzeugen.
